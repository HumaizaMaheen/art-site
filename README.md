# Crafterina_by_Humaiza 🎨

**Crafterina_by_Humaiza** is an interactive art reference website designed for beginners and art lovers. It provides easy-to-understand tutorials, a curated shop of art materials, and a smooth shopping experience powered by a mock API.

## 🖥️ Project Overview

This website is built to:
- Offer high-quality art references and resources
- Help users explore beginner-friendly tutorials
- Simulate an online art shop experience with cart and checkout features

## 📁 Pages Included

- **Home**: Introduction to the site and featured content
- **Shop**: A collection of art products polaroids (fetched using Mock API)
- **Tutorial**: Step-by-step beginner tutorials and tips
- **Cart**: Users can view and manage selected items
- **Checkout**: Simulated checkout process 

## ⚙️ Technologies Used

- **HTML/CSS/JavaScript**
- **Mock API (JSON Server / Fake Store API)**

- **Modular JavaScript** for organized code structure

## 🧪 Features

- Browse and filter products
- View detailed information using modals
- Add/remove items from the cart
- View subtotal and grand total
- Checkout summary
